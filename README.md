# Minicurso: Análise de Dados Genômicos sem Código

Bem-vindo ao repositório de apoio para o minicurso "Análise de Dados Genômicos sem Código: Uma Introdução Prática com Galaxy e Orange Data Mining".

## Objetivo

Capacitar os participantes a realizar um fluxo de trabalho básico de bioinformática, desde a obtenção de dados públicos até a análise e visualização interativa de resultados, utilizando exclusivamente ferramentas com interface gráfica e intuitiva.

## Conteúdo do Repositório

* **1_Apresentacao**: Contém o arquivo-fonte (`.qmd`) para os slides da aula, feitos em Quarto.
* **2_Tutorial_Alunos**: Guias passo a passo detalhados para cada um dos casos de estudo propostos.
* **3_Dados**: Códigos de acesso (SRA Accession) para os dados brutos utilizados na aula.
* **4_Material_Professor**: Um guia com dicas, pontos de atenção e possíveis erros dos alunos para auxiliar na condução do minicurso.

## Ferramentas Utilizadas

1.  **Galaxy Project (`usegalaxy.org`)**: Plataforma web para análise de dados biomédicos.
2.  **Orange Data Mining**: Software de código aberto para mineração e visualização de dados.
3.  **NCBI SRA**: Banco de dados público de sequências genômicas.

Este material foi desenhado para ser um ponto de partida. Sinta-se à vontade para explorar, modificar e aprofundar seus conhecimentos!
